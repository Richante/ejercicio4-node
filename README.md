# Ejercicio 4: Web Scraping con Node.js

Este ejercicio crea un servidor Node.js que descarga el HTML de una web y extrae información específica (los títulos de sección de Wikipedia de la página de JavaScript).

## ¿Cómo probar el código? (cuando tengas Node.js):
1. Instala Node.js y accede a esta carpeta.
2. Instala los paquetes necesarios:
npm install node-fetch cheerio

3. Ejecuta el servidor:
node scraper.js


4. Abre en el navegador: `http://localhost:3000`

## Notas de mejora:
- Puedes cambiar la URL de la web en el archivo `scraper.js`.
- Puedes modificar la lógica de extracción para obtener otros datos del HTML.
